Run Tests.vi

Caraya suite runner, generated by lvai_generate_caraya_test_runner.

It builds every test VI's path relative to its OWN location, so the suite moves with the folder, and runs them through Caraya's Run Tests.vi (Array Path instance) with Interactive FALSE - a TRUE there opens a modal report dialog, which stops LabVIEW's gRPC service until a human dismisses it.

Read the JUnit report named by 'Report Path used', not 'error out': the error cluster carries the FIRST failed assertion only.
