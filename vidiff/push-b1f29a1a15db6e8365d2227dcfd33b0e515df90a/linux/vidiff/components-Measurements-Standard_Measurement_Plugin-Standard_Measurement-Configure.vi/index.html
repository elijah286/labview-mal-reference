Standard Measurement Plugin.lvlib:Standard Measurement.lvclass:Configure.vi

Override configure.vi to setup any parameters for a measurement before acquiring.

Configure.vi is called by the 'Initialize Measurement Actor Core.vi,' which executes before Actor Core of the root measurement class. The root configure method populates the basic Measurement UI with information such as the hardware device in use and the name of the measurement. The base configure method calls 'Acquire.vi' once execution is complete. If beginning a recurring acquisition, it reset the iteration count to zero.
