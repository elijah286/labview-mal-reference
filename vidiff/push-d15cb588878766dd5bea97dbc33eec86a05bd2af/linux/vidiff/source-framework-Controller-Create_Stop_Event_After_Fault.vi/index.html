Create Stop Event After Fault.vi

Create the controller shutdown user event even when initialization failed. Return the original initialization error first, then event-creation error. No retry, wait or dialog. Input event data defines a string user event; output event is owned by the controller core and must be destroyed after its parallel loop joins.
