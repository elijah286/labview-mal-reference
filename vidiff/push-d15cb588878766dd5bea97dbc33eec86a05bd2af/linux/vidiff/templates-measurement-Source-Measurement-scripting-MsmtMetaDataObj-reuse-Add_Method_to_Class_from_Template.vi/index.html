MeasurementMetaData.lvclass:Add Method to Class from Template.vi

Given a template for a new method, this VI will create a new copy of this VI and add it to a Class. The copy of the new method will be stored in the same locaiton as the .lvclass file

error in can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.
