Build Path__ogtk.vi

Functions identically to LabVIEW "Build Path" function, but is polymorphic to also allow the path and/or input to be an array. There are two array modes:

(1) if "base path" and "name or relative path" are arrays then the output array is built element by element with the ideces of base path corresponding to those of "name or relative path"

(2) if "base path" is a literal and "name or relative path" is an array then the output array is build by appending each element in "name or relative path" onto base path.
