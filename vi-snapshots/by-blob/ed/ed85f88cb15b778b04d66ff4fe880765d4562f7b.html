Format Variant Into String__ogtk.vi

Overcomes a limitation of "Format Into String" by allowing variant data types to be used. This VI supports variant data for all LabVIEW data types supported by "Format Into String".

<b>Notes:</b>

<b>Format string</b> input may optionally be passed as a variant attribute named "Format String".

<b>ISO 8601</b> is used as the default formating for Timestamp unless otherwise specified. <b>Timestamp</b> data must use the <b>Format String:</b> %T (or variations of %T), otherwise it will return an error.
