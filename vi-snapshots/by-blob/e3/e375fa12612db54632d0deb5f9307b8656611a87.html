Resolve Timestamp Format__ogtk.vi

Resolves a <b>Timestamp Format</b> string. <b>ISO 8601</b> is used as the default formating for Timestamp unless otherwise specified.

<b>ISO 8601</b> is used with the following options:

Extended format

UTC

Decimal point (.) for decimal fractions (lowest order of time element is seconds)

3 Decimal places

<b>E.g:</b> [YYYY]-[MM]-[DD]T[hh]:[mm]:[ss]Z
