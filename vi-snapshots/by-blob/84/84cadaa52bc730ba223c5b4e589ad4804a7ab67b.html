Mangle VI Name (String)__ogtk.vi

Mangles a VI's name by applying a <b>namespace string suffix</b>.

<b>Name</b> may be a path or a string.

For example:

Name => "Widget.vi"

Namespace => "OpenG"

Mangled Name => "Widget__OpenG.vi"

Name => "Widget"

Namespace => "OpenG"

Mangled Name => "Widget__OpenG"

Name => "Widget.vi"

Namespace => "" (Note: blank string means do not mangle)

Mangled Name => "Widget.vi"

The error in cluster can accept error information wired from VIs previously called. Use this information to decide if any functionality should be bypassed in the event of errors from other VIs.
