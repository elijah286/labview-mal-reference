Merge Directories__ogtk.vi

Copies the contents of source directory into the destination directory. If source directory has subdirectories they will be copied into the destination directory recursively. Optionally, existing files may be overwritten, by setting the "Overwrite Existing Files?" input to TRUE. If you attempt to overwrite an existing file without setting to TRUE ans error will be returned. If FALSE, existing files will not be overwritten and no error wil be returned, Optionally, read-only files may be overwritten, by setting the "Ignore Read-Only?" input to TRUE. If you attempt to overwrite a read-only files without setting to TRUE an error will be returned. Optionally, by setting the "Delete Source?" input to TRUE the source directory will be deleted upon merge completion if no errors occured.
