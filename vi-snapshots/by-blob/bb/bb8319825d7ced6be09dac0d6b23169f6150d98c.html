Get All Control Values {Variant}__ogtk.vi

Gets all of the control of indicator values depending on the Boolean input Control. An input of TRUE will return all of the control while an input of FALSE will return all of the indicators.

<b>Note: </b>This VI used to call an IN that is now depreciated. As a result, this VI has become a redundant wrapper.

<b>This VI Is Depreciated</b>

Please use "Invoke Node:Ctrl Val.Get All" available from the Functions Palette.
