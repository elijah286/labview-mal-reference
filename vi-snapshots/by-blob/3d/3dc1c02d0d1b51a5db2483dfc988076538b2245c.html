Variant Array to Spreadsheet__ogtk.vi

Overcomes a limitation of "Array to Spreadsheet String" by allowing variant data types to be used. This VI supports variant data for all LabVIEW data types supported by "Format Into String". The "format string" for each Varriant element of the input array must be passed within each variant element as a variant attribute named "Format String".
