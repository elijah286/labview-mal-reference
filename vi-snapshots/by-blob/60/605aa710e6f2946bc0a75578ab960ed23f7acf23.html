Multi-line String to Array__ogtk.vi

Converts a multiline input string to a 1D array of lines (without EOLs). If the input string ends in an EOL, then the last line will be removed (since it is empty) -- this behavior is useful for instrument communication where the last line ends with a EOL character that we do not wish to treat as a seperate line (since it contains no data).
