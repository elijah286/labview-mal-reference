Filter 1D Array with Scalar (String)__ogtk.vi

This polymorphic VI filters out all instances of items to filter from the input array and outputs the result as filtered array along with an array of filtered item indices containing the indices of the items that were filtered. You can wire either a 1D array or a scalar value to items to filter.
