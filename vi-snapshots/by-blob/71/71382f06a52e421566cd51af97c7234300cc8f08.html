Find VI with Focus__ogtk.vi

Returns a reference to the frontmost VI panel.

This VI is reentrant (as indicated by the crosshatched background) so that references in use by one caller aren't closed by another. This also allows different callers to exclude different panels from consideration and to get a proper indication of whether a changed has occurred since their own last last call.

This is an enhancement of Jim Kring's Find Frontmost VI that returns a reference as well as a name, signals if this has changed since the last call, allows exclusion of VIs in the calling sequence of this VI or other VIs of the user's choice (useful for editing utilities that stay on top of all other windows), cleans up unused references, and runs, on average, 50 or more times faster.

Generates no errors.

Exclude Levels (call chain=-1)[Exclude Levels]

Allows a utility to follow the focus of the programmer by remembering the previously frontmost VI panel even when the programmer is manipulating the front panel of the utility.

Useful values are:

-1: Exclude all VIs in this VI's call chain.

0: Don't exclude anything.

1: Exclude only this VI.

2: Exclude this VI and it's immediate caller.

Exclude Names (none)[Exclude Names]

Additional utility VIs whose selection should not be considered a change of focus.

    		String

Exclude All Callers (T)[Exclude Callers]

Even callers of this VI that are not in the current call chain do not disturb the focus.

Overridden if Exclude Levels is 0 (none).
