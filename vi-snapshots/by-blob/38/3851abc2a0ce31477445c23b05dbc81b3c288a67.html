UnMangle VI Name__ogtk.vi

Unmangles a VI's name by removing a <b>namespace string suffix</b>.

<b>Name</b> may be a path or a string.

For example:

Mangled Name => "Widget__OpenG.vi"

Unmangled Name => "Widget.vi"

Namespace => "OpenG"

Mangled Name => "Widget__OpenG"

Unmangled Name => "Widget"

Namespace => "OpenG"

Mangled Name => "Widget.vi"

Unmangled Name => "Widget.vi"

Namespace => "" (Note: blank string means do not mangle)
