Write Panel to INI__ogtk.vi

Writes the values of the controls on the Front Panel of VI ref to a standard LabVIEW configuration (INI) file as key-value pairs.s

Use this VI in conjunction with the Read Panel from INI from the OpenG Variant Config palette.

Connector Pane

Front Panel
