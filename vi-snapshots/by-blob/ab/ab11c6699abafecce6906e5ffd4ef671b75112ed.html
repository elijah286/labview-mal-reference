Mangle VI Name__ogtk.vi

Mangles a VI's name by applying a <b>namespace string suffix</b>.

<b>Name</b> may be a path or a string.

For example:

Name => "Widget.vi"

Namespace => "OpenG"

Mangled Name => "Widget__OpenG.vi"

Name => "Widget"

Namespace => "OpenG"

Mangled Name => "Widget__OpenG"

Name => "Widget.vi"

Namespace => "" (Note: blank string means do not mangle)

Mangled Name => "Widget.vi"
