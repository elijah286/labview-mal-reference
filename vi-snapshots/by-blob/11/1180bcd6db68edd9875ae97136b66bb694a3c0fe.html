Convert EOLs__ogtk.vi

Converts all EOLs in the string to the type specified. A CRLF pair (\r\n) is considered to be one EOL. Therefore all CRLF pairs may be converted to just a CR or just a LF. Likewise single CRs or LFs may be converted to CRLF pairs. LabVIEW's Write File VIs have this option built into them, but Serial, TCP-IP, and others do not. There is no way to "escape" a CR, LF, or CRLF as not an EOL so be careful when using this utility.
